# Bubble Burst

A self-contained HTML5 bubble shooter built with Canvas, CSS, and vanilla JavaScript.

## Play

Open `index.html` in a modern web browser. No build step or external assets are required.

## Controls

- Aim with the mouse or touch, then click or tap the board to shoot.
- Tap the `NEXT` bubble or press Space to swap bubbles.
- Use the header buttons to toggle the landing marker, pause, restart, and mute audio.

## Features

- Staggered hexagonal bubble grid with cluster matching and floating-bubble drops.
- Reflected trajectory guide with an optional predicted landing cell.
- Level progression, ceiling-drop warnings, star bubbles, combos, and high-score saving.
- Responsive layout and synthesized sound effects.
